# Applied Analytics Portfolio

This repository contains selected academic analytics and machine learning projects completed as part of my MBA with an Artificial Intelligence concentration coursework at Stevens Institute of Technology.

## Featured Projects

### 1. Eureka Forbes Lead Generation Prediction
Built and evaluated machine learning models to identify website visitors most likely to convert, with the goal of improving digital marketing efficiency and targeting.

**Tools:** Python, pandas, scikit-learn, SMOTE, XGBoost, Tableau/Power BI concepts  
**Focus:** classification, imbalanced data, model comparison, business recommendations

### 2. Predicting Earnings Manipulation by Indian Firms
Developed fraud-detection models using financial indicators to identify potential earnings manipulation, with attention to class imbalance, threshold tuning, and interpretability.

**Tools:** Python, pandas, scikit-learn, SMOTE, logistic regression, random forest  
**Focus:** fraud analytics, feature importance, threshold selection, deployment planning
